## QUESTION #2 — S-BULL 調整例（231〜235 / 271〜275）と engine の最上位候補が異なる

**種別**: 戦術判断
**状態**: 報告のみ。データは無変更。

資料 (6) の S-BULL 調整例は、**算術・ルールとしてはすべて正しい**ことを検算済みです
（10 件すべてで、合計・残り・テンパイ成立を確認）。

一方、engine が同じ残り点で最上位に置く候補は資料と異なります。

| 残り | 資料の例 | 残り | engine の最上位 | 残り |
| --- | --- | ---: | --- | ---: |
| 231 | S20 + S19 + SB（64点） | 167 | T20 + T20 + S20（140点） | 91 |
| 271 | T19 + S19 + SB（101点） | 170 | T20 + T20 + T20（180点） | 91 |

**理由**: 91 は 2 本でも上がれ（T17 + D20）、上がりが D20 で、BULL を要求しません。
残りの質としては 167 / 170 より高く評価されます。加えて取得点も大きく上回ります。

**解釈**: 資料 (6) は「トリプルを使わなくても S-BULL で着地を整えられる」という
**技術の説明**であって、「その組み立てが常に最善である」という主張ではないと読めます
（実際、資料には「1本目に60が入った後」という前提が併記されています）。

**対応**: 資料の値はフィクスチャ（`src/data/setupReferenceCases.ts`）として保持し、
算術・ルール・テンパイ成立をテストしています。engine のランキングとの一致は要求していません。

**確認したいこと**: S-BULL を使う組み立てを、engine のランキングでも上位へ出したいですか？
その場合は「トリプルを使わない」ことへの加点など、明示的なルールを追加する必要があります
（ランキング思想の変更なので Human Approval が必要です）。

## NOTE #3 — 「180 後にテンパイになるのは下一桁が 0・1・4・7」の適用範囲

**種別**: 経験則の範囲
**状態**: 対応済み（帯を限定して実装）

資料 (3) に「180後にテンパイになるのは下一桁が **0・1・4・7** のとき／
**2・3・5・6・8・9** はテンパイにならない」とあります。

これは **340 点台（= 残り 159〜170 の帯）では正しい**ことを検算済みです。
ただし一般の残り点には拡張できません。反例:

- 152（下一桁 2）→ T20 + T20 + D16 で 3 本チェックアウト可能
- 158（下一桁 8）→ T20 + T20 + D19 で 3 本チェックアウト可能

**対応**: `LAST_DIGIT_RULE_BAND = { min: 159, max: 170 }` として帯を明示し、
`hasMemorableLastDigit()` は帯の内側でだけ true を返します。
加点も +6 と小さくし、実際の判定は engine の計算に委ねています。
UI の説明文にも「この帯に限った経験則です」と明記しています。

**資料の修正は不要**です（資料は 340 点台の文脈で書かれているため、その範囲では正しい）。

## NOTE #4 — Excel の収録範囲（41〜170 の 123 件）

**種別**: データ範囲
**状態**: 想定どおり

Excel には 41〜170 のうち **123 件**が収録され、欠けている 7 件は

```
159 / 162 / 163 / 165 / 166 / 168 / 169
```

でした。これは engine が計算した Bogey Number と完全に一致します。
**欠落は正しい**ため、対応は不要です。

## NOTE #6 — 「1 ビジットでテンパイを作れない残り」

**種別**: engine が見つけた事実（資料には無い）
**状態**: 情報

171〜350 のうち、そのビジットで何を取ってもテンパイにできない残り点は次の 7 件だけです。

```
339 / 342 / 343 / 345 / 346 / 348 / 349
```

これは **Bogey Number + 180** とちょうど一致します。
資料 (3) の 340 点台の表を、180 以外の得点も含めて一般化した結果にあたります。

UI ではこの状況を検出して「この残りからはテンパイを作れません」と伝えます。
教材として資料へ追記する価値があるかもしれません（**確認したいこと**）。
