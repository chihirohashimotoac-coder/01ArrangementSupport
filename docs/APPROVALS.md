# APPROVALS.md — 戦術方針の人間承認記録

このリポジトリの戦術データ（基準ルート・評価の重み・教材ルール）は、
**計算で一意に決まるものではなく、人間が選んだ方針**です。
このファイルは「誰が・いつ・何を承認したか」を残すための記録です。

---

## 用語について（重要）

このファイルに並ぶ値を、**「数学的・統計的に絶対正しい値」とは呼びません。**

- 算術・ルール上の正しさ（合計が LEFT と一致する、最終ダートがダブルである、
  Bogey かどうか、など）は engine が計算し、テストで検証しています。
  これは**検証可能な事実**です。
- 一方、「どちらのルートを推奨するか」「どの残しをより良いとするか」は
  **戦術的な価値判断**であり、計算だけでは決まりません。
  ここに記録するのはそちらです。

したがって本ドキュメントおよび関連ドキュメントでは、次の表現を使います。

| 使う表現 | 使わない表現 |
| --- | --- |
| 人間承認済みの v1 戦術方針 | 数学的に正しい値 |
| v1 暫定値 | 統計的に最適な重み |
| v1 で採用した思想 | 唯一の正解 |

v1 は**運用しながら見直す前提の暫定値**です。
変更するときは、このファイルへ v2 として追記し、あらためて人間の承認を得てください。

### A-1. 基準ルートの呼称

- 出典の一次資料が確認できていないため、PDC 公式であるとは主張しない。

- 関連: `docs/CHECKOUT_DATA_POLICY.md` §2、`docs/DATA_CONFLICTS.md` #1

### A-2. S-BULL 調整例（231〜235 / 271〜275）の位置づけ

添付資料の S-BULL 例は **「常に最適なルート」ではなく、S-BULL を使った SETUP 調整技術の教材例**として扱う。

- 10 件すべての算術・ルール・テンパイ成立は検証済み（フィクスチャとして保持）。
- engine のランキングがこれらを最上位に置くことは**要求しない**。
- 資料の記載は変更しない。
- 関連: `docs/SETUP_THEORY.md` §6、`docs/DATA_CONFLICTS.md` #2

### A-3. 「下一桁 0・1・4・7」の適用範囲

**159〜170 付近の対象帯に限定した教材ルール**として扱う。

- 一般の残り点へは拡張しない（152・158 が反例）。
- 実装は `LAST_DIGIT_RULE_BAND = { min: 159, max: 170 }` で帯を明示済み。
- 加点は +6 と小さく、実際の判定は engine の計算（`isCheckoutable`）に委ねる。
- 資料の記載は変更しない（340 点台の文脈では正しいため）。
- 関連: `docs/SETUP_THEORY.md` §3、`docs/DATA_CONFLICTS.md` #3

### A-4. LEFT 2〜40 の基準ルート

現在の `src/data/lowStandardRoutes.ts` の導出規則を **v1 の STANDARD 基準ルートとして承認**する。

- 採用ルール（R1: 偶数は 1 本上がり / R2: 奇数は 32 → 16 → 8 → 4 → 2 の順に立て直しやすいダブルを作る）
- 導出結果 39 件（2〜40）
- `reviewStatus` を `pending-human-review` から **`human-approved-v1`** へ変更。
- 関連: `docs/CHECKOUT_DATA_POLICY.md` §5、`docs/DATA_CONFLICTS.md` #5

### A-6. SETUP の重み

- `SETUP_POINTS_WEIGHT = 0.7`
- `SETUP_DIFFICULTY_WEIGHT = 12`

を **v1 暫定値として承認**する。
「同じ質の残りを作れるなら点を多く取る」「同じ点なら易しい的で取る」という順序を与える値です。

### A-7. 残り点の評価と 160 / 170 の順位

- `LEAVE_GOOD_FINISH_DOUBLE = 10`
- `LEAVE_REQUIRES_BULL = -8`

を承認し、その結果として **160 が 170 より上位に評価される現在の思想を v1 で採用**する。

理由: 160 は BULL を要求せず D20 で終われるため、170（T20 → T20 → BULL）より
組み立てが素直である、という戦術判断です。
「170 が最大だから最良」という数値順の考え方は採らない、という方針の具体化にあたります。

### A-8. GRADE_THRESHOLDS

現在の値（S = 差 0 / A = 差 25 以内 / B = 差 60 以内 / それ以外 C）を **v1 暫定値として承認**する。

あわせて、`DISCOURAGING_REASON_CODES` が付いたルートを（同じ欠点を持たない選択肢がある場合）
C とする仕組みも v1 の採点思想として承認済みです。
